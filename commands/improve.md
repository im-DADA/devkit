# /improve

"모델은 그대로, 지시가 똑똑해진다." 실수를 영구 가드레일로 바꾸는 회고 루프.

1. 이번 세션(또는 지정 범위)에서 아래 신호를 뽑음:
   - 사용자가 **고쳐준 것** (내가 틀렸던 지점)
   - **반복된 마찰** (같은 걸 여러 번 설명/재시도)
   - **잘 통한 패턴** (강화할 것)
   - **놓친 규칙** (있었는데 안 지킨 것)
2. 각 교훈을 devkit `RULES.md`·에이전트·스킬과 **대조** → 어디에 반영해야 재발 방지되는지:
   - 프로젝트 특수 → 프로젝트 `LEARNINGS.md`
   - 일반 규칙 → devkit `RULES.md` 수정 제안
   - 반복 워크플로우 → 새 커맨드/스킬 제안
3. **한 번에 하나씩** 제안 + 근거. 사용자가 accept/reject.
4. 결정을 `LEARNINGS.md`에 기록 — accept는 반영, **reject도 남겨서 재제안 방지**.

## 안티패턴 (지킬 것)

- 규칙 무한정 늘리지 말 것 — **비대해지면 오히려 무시됨**. 정말 반복되는 것만.
- "Never …" 금지 규칙엔 **반드시 대안 병기** (안 그러면 교착).
- 이미 있는 규칙과 중복/모순 금지 — 먼저 Grep으로 확인.
- 규칙이 자꾸 안 지켜지면 → 규칙이 아니라 **훅으로** 강제할지 검토.
