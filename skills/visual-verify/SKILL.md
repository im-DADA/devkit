# Visual Verify

"테스트 통과 ≠ 의도대로 보임." 웹 UI는 실제로 띄워서 눈으로 확인한다.

## 0. 전제 확인

- **연결된 브라우저 자동화 MCP** 필요 (Playwright MCP, claude-in-chrome 등). 사용 가능한 navigate/screenshot 계열 도구를 찾는다.
- 없으면 여기서 멈추고 설치 안내: "Playwright MCP 서버를 연결해야 함 (`/mcp` 또는 설정에서 추가)."

## 절차

1. **dev 서버 기동** — `package.json`의 `dev`/`start` 스크립트 탐색 → 백그라운드로 실행 → 포트 확인 (기본 3000/5173 등).
2. **페이지 열기** — 인자의 경로/URL로 브라우저 MCP navigate → **스크린샷**.
3. **비교**:
   - 레퍼런스 이미지(디자인/이전 스크린샷)가 주어지면 → vision으로 **레이아웃·간격·색·타이포·정렬 diff** 목록화.
   - 없으면 → 명백한 깨짐(오버플로우, 겹침, 빈 영역, 잘림) 점검.
4. **런타임 신호** — 콘솔 에러·네트워크 실패도 함께 확인.
5. **diff 보고** — 각 항목 "무엇이/어디서/어떻게 다른지". 수정은 사용자 확인 후 (또는 명시 요청 시).

## 주의

- 스크린샷은 **증거** — 추측으로 "잘 나옴" 하지 말 것.
- dev 서버 띄웠으면 끝나고 정리(종료) 안내.
